Ranger aussi dans :

Un code IMDb (tt…) est détecté automatiquement, film ou série. Pour un code TMDB numérique, choisis Film ou Série. Les liens IMDb et TMDB copiés depuis le navigateur fonctionnent aussi.

Formats acceptés : tt0068646, 550 (TMDB, type par défaut ci-dessous), tv:1396 / film:550, liens IMDb ou TMDB. Tout ce qui suit l'identifiant sur la ligne est ignoré (ex. tt0068646 Le Parrain). L'ordre de la liste est conservé comme file d'attente.
